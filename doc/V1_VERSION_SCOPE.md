# 应龙原型 V1.0 版本范围说明

## 版本定位

本原型同时保留了 V1.0 交付范围和部分后续版本方案，用于完整表达产品演进方向。为避免原型评审时将规划能力误判为 V1.0 承诺，所有超出范围的入口均以“V1不含”标识，并在对应页面补充范围说明。

## V1.0 暂不包含

1. 链路追踪：完整模块不属于 V1.0。
2. 模型训练：训练任务、训练详情和训练记录不属于 V1.0。
3. 模型仓库（模型资产）中的训练版本：版本历史、训练记录追溯及相关操作不属于 V1.0。
4. 添加模型资产：模型资产页面的手动添加能力不属于 V1.0。
5. 编辑模型资产：模型资产卡片的编辑入口及编辑弹窗不属于 V1.0。
6. 模型资产卡片中的版本数量：卡片右上角的版本数量展示不属于 V1.0。
7. 部署服务中的镜像选择：镜像路径和镜像仓库选择不属于 V1.0，V1.0 使用平台默认镜像。
8. 任务详情中的在线测试：`sys_task_detail.html` 的在线测试入口及交互不属于 V1.0。
9. 集群管理中的加速卡容量：集群概览中的加速卡容量指标不属于 V1.0。
10. 集群管理中的 GPU 利用率：节点列表及节点详情中的 GPU 利用率指标不属于 V1.0。
11. 算力调度中的请求数趋势：请求数趋势图表及相关数据不属于 V1.0。
12. 任务详情中的按天 / 按小时统计：按天和按小时的统计明细及相关分页仅作后续版本方案预览，不属于 V1.0。

## 原型标注规则

- 全局侧栏提供“V1.0 范围说明”入口，可集中查看上述 12 项范围。
- “模型训练”和“链路追踪”导航入口显示“V1不含”。
- 进入完整排除的页面后，页面标题下方显示橙色版本范围提示。
- 局部排除的功能在对应按钮或操作入口旁显示“V1不含”。
- 被标注的页面和交互仅用于后续版本方案沟通，不作为 V1.0 的开发、交付或验收依据。
