依据 PROTOTYPE_DESIGN-V4.md 展示桌面端 B 类管理平台规范；不设置独立全局顶栏和层级导航。

V4 修订说明 — 依据《设计规范优化内容》建议要点 2026-09-01 · 架构委员会
  • 应用框架：桌面端采用“左侧导航 + 页面标题与操作区 + 主内容区”；用户入口固定在侧栏底部。
  • 色彩体系：补充告警色（红 #E11D48）与安全色（绿 #059669）功能语义 Token；新增文字四级颜色 #0F172A / #1E293B / #334155 / #64748B（对应 Slate-900/800/700/500）。
  • 状态胶囊：维持 V3 原规范不变。
  • 文字规范：第 3 章由「排版阶梯」升级为「文字使用规范」，补充中文字体栈与数字字体 DIN 规范，明确四级行高（28 / 24 / 22 / 18px）与使用场景。
  • 表单控件：新增下拉菜单专项规范 —— 文字 14px、行高 32px、已选项文字品牌蓝 #266EFF；输入框与表单标签统一 Body 14px。
  • 列表组件：列表正文统一遵循 Body 文字规范（14px / 行高 22px / #334155）。
  • 模态框：明确提交操作按钮组统一右对齐。
  • 图表规范：图例与坐标轴注释最小字号统一 12px；新增条形统计图（横向条形 / 纵向柱状）规范。
  • 图标卡片：明确三级文字 —— 标题 16px / 正文 14px / 说明行 12px。
  • 时间筛选：时间选择器文字 14px，日期选择最小字号 12px。
裁决说明：原建议「下拉菜单 hover 背景 rgba(0,0,0,0.4)」在白色菜单底上形成约 #A6A6A6 背景，与正文 #334155 对比度约 2.5:1，低于可读性标准（WCAG AA 要求 4.5:1）。本次统一调整为 rgba(0,0,0,0.04)（等价 Slate-100 #F1F5F9），保留"黑色半透明 hover"机制的同时保障可读性；其余建议均已原文采纳。
